## JR Club MVP

- Stack: Laravel 12, Inertia React TypeScript, Tailwind CSS, Laravel Reverb, database queues, and PWA service worker support.
- Domain models: sports, activities, activity participants, teams, team members, leagues, league awards, league teams, league entries, league groups, league group entries, matches, and match sets.
- Roles: `users.role` is `member` or `admin`; admin-only write actions are guarded by the `admin` Gate. Every user belongs to one branch through `users.branch_id`; `branch.is_global = true` marks Pusat/headquarters and grants all-branch access only to admins.
- Seed credentials for local development: `admin@jasaraharja.co.id` / `password`.
- Main authenticated routes: `/activities`, `/teams`, `/leagues`, `/matches/{match}`, `/leaderboards`, `/profile/show`, and the admin area under `/admin`. Admin ops include league schedule generation, bracket shuffling, substitutions, photo uploads, and Excel participant import/export. Branch admins manage only own-branch leagues/activities/teams/users; Pusat admins manage all branches and national content.
- `start_stage = bracket` leagues support a predetermined bracket draw ("preset reveal"): admins enable a per-league preset via `PATCH /admin/leagues/{league}/bracket/preset`, set a reveal number `N`, and pre-assign the first-round slot layout (`bracket_preset_slots`, entry id or BYE per slot). A `bracket_seed_count` counter increments on every "Seed brackets" click; on the Nth click `BracketService::seedBrackets` places entries directly from the preset slots (bypassing automatic bye placement) and the counter resets to `0`. All other seeds keep normal behavior.
- UI Layouts: The app uses responsive layouts where mobile renders a bottom navigation (member) or drawer sidebar (admin) and single-column layout, and desktop (`md:` or `lg:`) expands with a permanent sidebar and multi-column grid lists for data-dense pages.
- League categories are sport-bound via `sport_categories`; Badminton uses `MS`, `WS`, `MD`, `WD`, `XD` direct-entry formats, while Basketball seeds `3V3` and `5V5` team formats. Leagues keep denormalized `category` and derived `entry_type`, plus `participant_total`, `start_stage` (`group` or `bracket`), group/bracket advancement counts, nullable `match_format` backed by `App\Support\MatchFormat`, set-based scoring with `sets_to_win` / `points_per_set`, nullable `branch_id` where `null` means national/shared content, and optional league-level awards shown on member league detail pages. Null `match_format` keeps first-to-sets-to-win behavior; configured formats add Padel all-sets/single-block modes and Tenis Meja deuce win-by-2 validation.
- UI screens should continue translating the approved templates under `template/*/code.html` and tokens from `prompter/design-system.md`.
